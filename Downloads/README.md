# BeatMeat macOS development preview

Download [the DMG](BeatMeat-macOS.dmg?raw=1) or [the app ZIP](BeatMeat-macOS.zip?raw=1). Requires macOS14+, Intel or Apple Silicon. Copy BeatMeat.app to Applications. This development preview is ad-hoc signed, not notarized.

The complete validation record is in BeatMeat-validation.json. SHA256SUMS.txt covers the native downloads and validation record. [Feature coverage](../Docs/FEATURE_COVERAGE.md) lists the manual features that remain unimplemented.
